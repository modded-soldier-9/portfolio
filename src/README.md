# Source Subsystem

## Overview
Primary application source tree for the portfolio and Windows 7 Aero simulation web application, grouping Next.js application routes, classic desktop applications, UI components, static configuration, data stores, core operating system services, games, and global state.

## Subdirectories & Boundaries
- App: [./app/README.md](./app/README.md) - Next.js App Router root layout, viewport, global CSS, and page entry point
- Apps: [./apps/README.md](./apps/README.md) - Modular application registry, contracts, and classic accessories (Calculator, Explorer, Notepad, Paint)
- Components: [./components/README.md](./components/README.md) - Desktop shell, Superbar taskbar, Start Menu, floating gadgets, Web Audio synthesizer, and window clients
- Config: [./config/README.md](./config/README.md) - Site metadata, navigation items, and author profile configuration
- Contexts: [./contexts/README.md](./contexts/README.md) - React theme context provider and theme switching hooks
- Core: [./core/README.md](./core/README.md) - Foundation modules: GSAP animations, vector SVG assets, boot sequence, login screen, shell, and window manager
- Data: [./data/README.md](./data/README.md) - Structured portfolio data for certifications, education, work experience, and featured projects
- Games: [./games/README.md](./games/README.md) - Windows 7 entertainment titles (Hearts, Minesweeper, Solitaire)
- State: [./state/README.md](./state/README.md) - Central operating system state store, session lifecycle, virtual file system, and personalization
- Types: [./types/README.md](./types/README.md) - Shared TypeScript domain interfaces for navigation, education, and credentials
