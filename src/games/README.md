# Games

## Overview
Classic Windows 7 entertainment titles built with authentic visual style, accurate rule systems, sound effects, and physical animations.

## Subdirectories & Boundaries
- Hearts: [./hearts/README.md](./hearts/README.md) - 4-player trick-taking card game against named AI opponents with passing and Shoot the Moon rules
- Minesweeper: [./minesweeper/README.md](./minesweeper/README.md) - Grid puzzle game with Beginner, Intermediate, and Expert difficulties, safe-first click, and number chording
- Solitaire: [./solitaire/README.md](./solitaire/README.md) - Klondike Solitaire card game featuring Draw 1 / Draw 3 modes, drag-and-drop, hints, and auto-complete
- Space Cadet: [./space-cadet/README.md](./space-cadet/README.md) - 3D Pinball for Windows Space Cadet arcade table with 2D canvas physics, flippers, and procedural audio
