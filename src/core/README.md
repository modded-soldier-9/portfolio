# Core System

## Overview
Foundational architecture of the Windows 7 simulation, grouping centralized animation timelines, vector visual assets, boot sequence state machines, login authentication screens, desktop shell environments, and the shared Aero Glass window manager.

## Subdirectories & Boundaries
- Animation: [./animation/README.md](./animation/README.md) - Centralized GSAP animation presets, easing curves, and micro-interaction timelines
- Assets: [./assets/README.md](./assets/README.md) - 100% vector SVG icons, UI backgrounds, and 52-card playing card deck
- Boot: [./boot/README.md](./boot/README.md) - BIOS-less boot sequence featuring swirling firefly orbs and Windows 7 flag assembly
- Login: [./login/README.md](./login/README.md) - Welcome screen with customizable user profile, password input, and Aero transition
- Shell: [./shell/README.md](./shell/README.md) - Desktop wallpaper, icon grid, marquee selection, taskbar, and Start Menu integration
- Window Manager: [./window-manager/README.md](./window-manager/README.md) - Translucent Aero Glass window chrome, resizing, dragging, and Aero Snap docking
